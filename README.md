# AltSTU Schedule Bot

Telegram-бот для просмотра расписания занятий Алтайского государственного технического университета (АлтГТУ).

## Возможности

- Просмотр расписания на сегодня и завтра.
- Поиск учебных групп через API сайта АлтГТУ.
- Сохранение выбранной группы для каждого Telegram-чата.
- Отображение времени занятий, названий предметов, аудиторий, преподавателей и подгрупп.
- Интерактивные кнопки для навигации по расписанию.

## Технологии

- Python 3.11+
- aiogram 3
- aiohttp
- BeautifulSoup4
- aiosqlite
- SQLite

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone https://github.com/ТВОЙ_ЛОГИН/altstu-schedule-bot.git
cd altstu-schedule-bot
```

### 2. Установка зависимостей

Рекомендуется создать виртуальное окружение.

Windows:

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
```

Linux:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

Установи зависимости:

```bash
pip install -r requirements.txt
```

### 3. Настройка токена

Создай Telegram-бота через [@BotFather](https://t.me/BotFather) и получи токен.

**Windows PowerShell:**

```powershell
$env:BOT_TOKEN = "твой_токен"
```

**Linux:**

```bash
export BOT_TOKEN="твой_токен"
```

Не публикуй токен в исходном коде и не передавай его другим людям.

### 4. Запуск

```bash
python main.py
```

## Команды бота

| Команда | Описание |
|---|---|
| `/start` | Запуск бота |
| `/group` | Выбор или смена учебной группы |
| `/today` | Расписание на сегодня |
| `/tomorrow` | Расписание на завтра |

## Источник расписания

Расписание и данные об учебных группах получаются с сайта [АлтГТУ](https://www.altstu.ru/).

Поиск групп выполняется через мобильный интерфейс сайта. Выбранная группа сохраняется в локальной базе SQLite.

## Разработка

Проект использует асинхронную обработку запросов через aiogram 3 и aiohttp.

При развёртывании на сервере необходимо задать переменную окружения `BOT_TOKEN` и обеспечить сохранение файла SQLite между перезапусками.
